# Copy Code Reference with Line Numbers

A lightweight, productivity-boosting plugin that lets you copy file paths combined with selected line numbers in the format `relative/path/to/file:startLine~endLine` (or `relative/path/to/file:line` if only one line is selected).

### How to Use:
1. Select any block of code inside the editor.
2. Right-click to open the context menu and select **Copy Code Reference (Line Numbers)**, or press **Shift + Alt + C**.
3. The reference link is copied to your clipboard.

### Example Reference:
`src/main/java/com/ccsoftware/copycodereference/CopyCodeReferenceAction.java:18~57`
